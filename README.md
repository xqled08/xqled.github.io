# XQLED PicMaster 功能说明文档

## 简介

XQLED PicMaster 是一款功能强大的智能图片处理工具，支持图片裁剪、润色、水印、压缩、批量处理等多种功能。

---

## 功能模块说明

### 1. 图片导入模块

#### 功能描述
打开本地图片文件进行编辑，支持多种图片格式。

#### 操作步骤
1. 在左侧菜单栏找到「图片导入」模块
2. 点击「打开图片」按钮
3. 在弹出的文件选择对话框中，选择需要编辑的图片文件
4. 点击「确定」即可打开图片

#### 功能按钮
- **打开图片**：从本地选择并打开图片文件
- **云端模版**：查看和应用预定义的云端模版

---

### 2. 图片裁剪模块

#### 功能描述
对图片进行裁剪操作，支持自定义裁剪尺寸和位置。当原始图片小于设置的裁剪尺寸时，会创建透明背景并居中放置。

#### 操作步骤
1. 在左侧菜单栏找到「图片裁剪」模块
2. 在宽度和高度输入框中输入目标尺寸（单位：像素）
3. 点击「应用尺寸」按钮更新裁剪框大小
4. 在画布上拖动裁剪框到合适位置，或调整裁剪框边缘
5. 点击主界面的「裁剪」按钮执行裁剪操作

#### 特殊功能
- **智能扩展**：当设置的尺寸大于原始图片时，自动创建透明背景并将原图居中放置
- **保存模版**：将当前的裁剪尺寸和位置保存为模版
- **加载模版**：加载之前保存的裁剪模版
- **居中裁剪框**：打开新图片时，裁剪框自动居中于图片

#### 参数说明
- **宽度**：裁剪区域的宽度（像素）
- **高度**：裁剪区域的高度（像素）

---

### 3. 图片润色模块

#### 功能描述
调整图片的亮度、对比度和饱和度，支持预览和保存润色配置。

#### 操作步骤
1. 在左侧菜单栏找到「图片润色」模块
2. 拖动亮度滑块调整图片亮度（0-200%）
3. 拖动对比度滑块调整图片对比度（0-200%）
4. 拖动饱和度滑块调整图片饱和度（0-200%）
5. 调整过程中会自动预览效果
6. 点击「应用润色」按钮确认修改
7. 可以点击「保存润色模版」保存当前设置，或「加载润色模版」应用已保存的配置

#### 参数说明
- **亮度**：调整图片的明暗程度，100% 为原始亮度
- **对比度**：调整图片的明暗对比程度，100% 为原始对比度
- **饱和度**：调整图片的颜色鲜艳程度，100% 为原始饱和度

---

### 4. 水印功能模块

#### 功能描述
添加文字或图片水印到图片上，支持自定义位置、大小、颜色和透明度。

#### 操作步骤
1. 在左侧菜单栏找到「水印功能」模块
2. 选择水印类型（文字水印或图片水印）

##### 文字水印操作
1. 选择「文字水印」单选项
2. 在「水印文字」输入框中输入要添加的文字
3. 调整文字大小（10-200%）
4. 点击「水印颜色」选择颜色
5. 调整透明度（0-100%）
6. 选择水印位置（左上、右上、左下、右下、居中、平铺）
7. 点击「预览水印」查看效果
8. 满意后点击主界面的「保存」按钮保存图片

##### 图片水印操作
1. 选择「图片水印」单选项
2. 点击「选择」按钮选择水印图片
3. 调整水印图片大小（10-200%）
4. 调整透明度（0-100%）
5. 选择水印位置
6. 点击「预览水印」查看效果
7. 满意后点击主界面的「保存」按钮保存图片

#### 功能按钮
- **预览水印**：在画布上预览水印效果
- **保存模版**：保存当前水印配置
- **加载模版**：加载已保存的水印配置

---

### 5. 图片压缩模块（新增）

#### 功能描述
压缩图片大小，支持按比例压缩或自定义尺寸压缩，可调整压缩质量。

#### 操作步骤
1. 在左侧菜单栏找到「图片压缩」模块
2. 选择压缩模式（按比例压缩或自定义尺寸）

##### 按比例压缩
1. 选择「按比例压缩」单选项
2. 拖动压缩比例滑块（10%-100%）调整压缩比例
3. 调整压缩质量（10%-100%）
4. 点击「预览压缩」查看效果
5. 满意后点击「应用压缩」确认修改

##### 自定义尺寸压缩
1. 选择「自定义尺寸」单选项
2. 输入目标宽度和高度（像素）
3. 调整压缩质量（10%-100%）
4. 点击「预览压缩」查看效果
5. 满意后点击「应用压缩」确认修改

#### 参数说明
- **压缩比例**：按比例缩小图片（10%-100%）
- **宽度/高度**：自定义输出尺寸（像素）
- **压缩质量**：控制输出图片的质量，质量越高文件越大（10%-100%）

#### 功能按钮
- **预览压缩**：在画布上预览压缩效果
- **应用压缩**：确认压缩并应用到图片

---

### 6. 批量处理模块

#### 功能描述
一次性处理多张图片，支持加载模版进行批量操作。

#### 操作步骤
1. 在左侧菜单栏找到「批量处理」模块
2. 点击「选择图片」选择要批量处理的图片
3. 在弹出的模版选择对话框中：
   - 可以选择「跳过」某类模版
   - 可以点击「选择」加载已保存的模版
4. 选择好模版后，点击「开始处理」执行批量操作
5. 处理完成后会自动保存到指定目录

#### 模版选择
- **裁剪尺寸模版**：加载预定义的裁剪尺寸和位置
- **润色模版**：加载预定义的亮度、对比度、饱和度设置
- **水印模版**：加载预定义的水印配置

---

### 7. 导出保存模块

#### 功能描述
保存处理后的图片，支持多种格式导出。

#### 操作步骤
1. 完成图片编辑后，点击主界面的「保存」按钮
2. 选择保存位置和文件名
3. 选择保存格式
4. 点击「保存」完成导出

## 快捷键和辅助功能

### 主界面操作
- **裁剪**：应用当前裁剪区域
- **重置**：恢复到原始图片
- **保存**：保存当前编辑的图片

### 其他功能
- **外观**：在深色/浅色模式之间切换

## 模版系统

### 保存模版
1. 配置好相应功能的参数
2. 点击「保存模版」按钮
3. 选择保存位置和文件名
4. 模版会保存为 JSON 格式

### 加载模版
1. 点击「加载模版」按钮
2. 选择之前保存的模版文件
3. 配置会自动应用到当前图片

### 支持的模版类型
- 裁剪模版（包含位置和尺寸）
- 润色模版（包含亮度、对比度、饱和度）
- 水印模版（包含类型、文字、图片、位置等）

---

## 注意事项

1. **图片备份**
   - 处理前建议先备份原始图片
   - 可以随时点击「重置」恢复原始图片

2. **系统要求**
   - 支持的图片格式：JPG、JPEG、PNG、BMP、GIF
   - 建议图片大小适中，过大图片可能处理较慢
